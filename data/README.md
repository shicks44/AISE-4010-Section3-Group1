# Data

The raw file is not stored in this repository because of its size (about 124 MB). The notebook downloads it into this folder on its first run from:

https://data.open-power-system-data.org/time_series/2020-10-06/time_series_60min_singleindex.csv

To place it by hand, save `time_series_60min_singleindex.csv` in this folder.

Citation: Open Power System Data. 2020. Data Package Time series. Version 2020-10-06. https://doi.org/10.25832/time_series/2020-10-06 (primary data from the ENTSO-E Transparency Platform).
